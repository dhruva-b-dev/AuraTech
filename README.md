# ⚡ AURA TECH — Modern Tech E-Commerce App

**AURA TECH** is a native Android e-commerce application designed with a high-contrast neo-dark aesthetic. Built entirely using modern Android development practices and Jetpack Compose, it showcases a fluid shopping experience for high-end audio gear and tech accessories.

### ✨ Key Features
- **Dynamic Home Dashboard:** Categorized tech sectors, flash deal timers, and promotional hero banners.
- **Detailed Product Catalog:** Interactive audio specs display, custom color selection, and integrated review metrics.
- **Cart & Checkout Management:** Real-time price breakdown, shipping eligibility bar, and interactive item counters.
- **User Profile Hub:** Tier-based loyalty membership tracking, active order statuses, and wallet top-ups.
- **Modern UI Architecture:** Custom dark theme design system built with Jetpack Compose and clean UI patterns.

### 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Design System:** Custom Material 3 Dark Theme
- **Architecture:** Clean Architecture / MVVM
